# 共同本棚・読書共有アプリ 要件定義
版 0.2 ／ 更新日 2026-11-05 ／ UI採用済み・一部運用は仮案

## 目的と担当

仲のよい人と本棚を作り、「今これを読んでいる」が伝わる場所にする。みんなが読んだ本を保存し、後から探せる。フロントはCodex、Goの業務実装は利用者が担当する。

## 採用した機能

| 機能 | 受入条件 |
| --- | --- |
| 共同本棚 | 1人でも招待メンバーとでも使える。最大4人は仮案 |
| 各人の段 | 各人が追加した本を新しい順に直近6冊表示。横スクロール可能。6冊は仮値 |
| 全冊ライブラリ | 段にない本もタイトル・著者・追加者・読了者を表示 |
| 検索 | タイトル・著者検索、メンバー絞り込み、読了のみ表示 |
| 登録 | ISBN手入力・バーコードで検索し、確認後に登録。取得失敗・結果なしを表示 |
| 状態共有 | 本人が未読・読書中・読了を更新し、メンバーは読書中・読了者を見られる |
| 履歴保持 | 古い本も保存。棚をアーカイブして読了記録を閲覧できる案 |

読書時間・読書速度・現在ページを初期版から外す。旧案のドラッグ並び替え・自由座標・段数指定は今回の追加日時順表示から外す。採用する際は並び順の仕様を追加する。

名称「綴り」、リアクション、みんなの本を混ぜる表示は提案機能。現在のモックは再読み込みで初期化される。製品版では登録本・読書記録を永続化する。

## API改訂案

| Method | Endpoint | 用途 |
| --- | --- | --- |
| GET | /api/health | DB接続確認・実装済み |
| GET | /api/books/search?isbn=... | 外部書誌検索 |
| GET / POST | /api/shelves | 参加棚一覧 / 作成 |
| GET / PATCH | /api/shelves/{shelfId} | 棚詳細 / 名称変更・アーカイブ・再開 |
| GET | /api/shelves/{shelfId}/members | メンバー |
| GET / POST | /api/shelves/{shelfId}/books | 全冊一覧 / 登録 |
| GET / PATCH | /api/shelves/{shelfId}/books/{bookId} | 詳細 / 書誌訂正 |
| GET | /api/shelves/{shelfId}/recent | 各人の直近6冊 |
| GET | /api/shelves/{shelfId}/reading | 今読んでいる本 |
| PUT | /api/shelves/{shelfId}/books/{bookId}/reading/me | 本人の読書状態更新 |

一覧にはq、memberId、finishedOnly、cursor、limitを指定する。memberId単独は追加者または読了者で一致させ、finishedOnly併用ではその人が読了した本を対象とする。招待APIは方式確定時に追加する。

本人IDは検証済み認証情報から確定する。未認証401、権限なし403、対象なし404、入力不正400、競合409、外部障害502、DB障害503を基本とする。

## 仮案と未確定事項

ownerだけが招待・メンバー管理・アーカイブできる案。他人の登録本編集、脱退、所有者移譲、認証サービス、招待方法、重複ISBN、誤登録訂正、アカウント削除は実装前に決定する。

アーカイブ・再開は履歴保持のための仮案。旧案の「棚削除後は個人ライブラリに戻す」を置き換える。

## 検証の順番

Aが棚と本を作成しBに共有 → 各人の読書状態とCのアクセス拒否 → 古い本の検索 → 読了・再読・アーカイブで履歴保持 → 競合と再送 → 認証込みのAWS検証。
