# 綴り — 共同本棚・読書共有アプリ
更新日 2026-11-17 ／ 提出用スコープ

本棚を共有し、「いま何を、どこまで読んでいるか」をひとことで残す。
近況カードは表紙またはタイトル・著者、投稿時刻、現在ページ、読書中／サボり中／読了、本人の感想で構成する。
感想にはネタバレ指定を付け、読む人が操作するまで隠す。

- スマホ幅の縦フィードをホームにする。全冊は独立した「本」タブのリストで保持する。
- 最新の状態はReadingRecords、過去の投稿はReadingPostsに分ける。
- サボり中は本人が選ぶ休止状態。自動判定や催促は行わない。
- 返信・写真アップロード・キャラ・リアクションは提出後。setlogの返信仕様は確認していない。
- 手入力登録を基本にし、ISBN検索・表紙取得は基本動作の完成後に追加。
- 読書時間は計測しない。現在ページは今回から採用する。
- 公開共同利用には認証・認可が必要。ローカルの架空メンバー表示とは区別する。

要件は [requirements.md](requirements.md)、実装との差は [development-status.md](development-status.md) を参照。
