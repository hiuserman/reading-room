# 2D仮想本棚・共同読書管理アプリ 企画案

更新日 2026-11-05

## 作りたい体験

一緒に使う人を選んで本棚を作り、読みたい本やおすすめの本を並べる。メンバーが「今これを読んでいる」と分かることで、本を通じた会話につなげる。

1人だけの本棚も、複数人の本棚も同じ仕組みで扱う。参加人数は作成者を含めて1〜4人程度を想定する。

## 今回の設計方針

- 本棚を共同利用の単位にする。
- 本棚の本と並び順をメンバーで共有する。
- 読書状態はユーザーごとに記録する。
- 読書中であることを棚のメンバーに表示する。
- 読書時間推定、読書速度、現在ページの記録は初期版の対象外とする。現在ページの除外は、読書時間パラメーターを外す意向を踏まえた整理。
- 書誌情報はISBN検索で取得し、登録時点の書名・著者・表紙などを棚の本に保存する案を採る。
- フロントエンドをCodex、バックエンドの実装を利用者が担当する。

## 基本の利用手順

2026-11-05のUI採用を反映。各メンバーの段に追加順で直近6冊を横スクロール表示し、全冊をリスト型ライブラリで保存・検索する。読了した人も表示する。以下の初期案にある手動並べ替えは、現在の追加日時順表示に置き換える。

1. 本棚を作る。
2. 一緒に使う人を招待する。自分1人でも使える。
3. ISBNを検索し、本を棚に追加する。
4. 各人の直近6冊を横スクロールで見る。過去の本を全冊ライブラリで探す。
5. 自分の読書状態を変更する。
6. 棚を開くと、メンバーが今読んでいる本が分かる。

## 要件定義で確定させる案

| 論点 | 現時点の案 |
| --- | --- |
| 人数上限 | 作成者を含め4人 |
| 招待と棚のアーカイブ | 作成者が操作する案。履歴を保持する |
| 本の追加・編集 | メンバーが追加。編集権限・誤登録訂正は要確認。自由配置は初期版対象外 |
| 招待参加 | 招待された本人の承諾後にメンバーになる |
| 読書状態 | 未読・読書中・読了。初期値は未設定として扱う |
| 状態の公開範囲 | 読書中・読了した人をメンバーに表示。未読の公開範囲は要確認 |
| 同じISBNの扱い | 同じ棚への重複登録は要確認 |
| 脱退・棚削除 | 本と個人の読書状態を残す範囲は要確認 |
| 認証 | ユーザー識別と棚への参加権限をAPIで確認。認証方式は要確認 |
